# AVERLI STUDIO

Independent brand, design and marketing studio.

Website: https://brigitabagovic.github.io/averli-studio/

This repository contains the static website in `docs/`. GitHub Pages should publish the `main` branch's `/docs` folder. Original template motion and transitions are retained; portfolio content and media belong to the studio.

The hero uses the newest supplied Subtitle.mp4 export. In-view playback, pause/replay and reduced-motion controls are included.

Page content is pre-rendered so text readers can access the site without running JavaScript. `docs/llms.txt` provides a plain-text content summary.
